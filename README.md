# 🪙 زر و ارز (ZAR & ARZ 3D)
### پلتفرم لوکس سه‌بعدی و تعاملی نبض قیمت طلا، سکه و ارز
> یک وب‌اپلیکیشن کامل، مدرن و تعاملی با تلفیق هنر سه‌بعدی **Three.js WebGL**، معماری کد تمیز، سرور اختصاصی پایتون و پایگاه‌داده محلی SQLite، همگام با نرخ‌های زنده **TGJU.org**.

---

## ✨ ویژگی‌های برجسته پلتفرم

* **موتور گرافیکی سه‌بعدی تعاملی (WebGL PBR Engine):**
  * شمش طلای سوئیسی با عیار ۹۹۹.۹ و بازتاب‌های نوری دینامیک استودیویی.
  * سکه‌های طلای چرخان بهار آزادی با جلوه‌های ژیروسکوپی ماوس.
  * کهکشان ۲۵۰۰+ ذره نوری طلایی معلق با جریان سیال در فضا.
  * حرکت سینمایی دوربین در فضا متناسب با پیمایش و اسکرول کاربر (Scroll-driven Camera Flythrough).
* **تابلوی زنده نبض بازار (Market Pulse):**
  * پوشش زنده طلای ۱۸ و ۲۴ عیار، مثقال (مظنه)، انواع سکه، دلار بازار آزاد، درهم امارات، یورو و تتر.
  * نمودارهای نوسان ۲۴ ساعته خطی (Sparkline SVG) و نمایش سقف و کف روز.
* **ماشین‌حساب هوشمند و سه‌بعدی (3D Vault Calculator):**
  * تبدیل دقیق اوزان از **۱۰ سوت تا ۱۰ کیلوگرم** (سوت، گرم، مثقال، کیلوگرم، اونس تروا).
  * واکنش فیزیکی و تغییر ابعاد شمش طلای سه‌بعدی در صفحه به ازای وزن انتخابی کاربر.
  * صدور فاکتور شفاف طلافروشی (ارزش خام + اجرت ساخت + سود قانونی ۷٪ + مالیات بر ارزش افزوده ۹٪ روی سود و اجرت).
  * خوانش هوشمند به حروف فارسی جهت جلوگیری از خطای خواندن صفرها.
  * تبدیل‌گر دوطرفه ارز با امکان تعیین نرخ دستی یا لحظه‌ای.
* **بک‌اند و پایگاه‌داده رایگان و مستقل:**
  * سرور یکپارچه پایتون بدون نیاز به نصب پکیج‌های خارجی.
  * پایگاه‌داده سریع و تعبیه‌شده **SQLite** برای ذخیره دائمی تاریخچه قیمت‌ها.
  * ورکر پس‌زمینه خودکار برای به‌روزرسانی اطلاعات از سایت مرجع **TGJU.org**.

## 🏗 ساختار مهندسی و معماری ماژولار (Clean Architecture)

```
zar-va-arz/
├── backend/                  # لایه سرور و سرویس‌ها
│   ├── app.py                # نقطه ورود سرور، هندلرهای REST API و روت‌های وب
│   ├── config.py             # پیکربندی سرور، آدرس‌ها، دیتابیس و دارایی‌ها
│   ├── database/             # لایه پایگاه‌داده (Database Layer)
│   │   ├── __init__.py
│   │   └── db_manager.py     # مدیریت SQLite، اسکیما، تراکنش‌ها و تاریخچه قیمت
│   └── services/             # لایه منطق بیزینس و ارتباطات خارجی (Service Layer)
│       ├── __init__.py
│       └── tgju_service.py   # وب اسکرپر، تبدیل واحدها و نرمال‌سازی داده‌های TGJU
│
├── frontend/                 # لایه ارائه‌ی کاربری (Client-side Presentation Layer)
│   ├── index.html            # کد سمانتیک HTML5 با پشتیبانی کامل از RTL و دسترسی‌پذیری
│   ├── css/
│   │   └── style.css         # سیستم دیزاین لوکس تیره، افکت شیشه‌ای و انیمیشن‌ها
│   └── js/
│       ├── main.js           # ارکستراتور کلاینت، بایند رویدادها و ارتباط با API
│       ├── scene3d.js        # موتور رندر سه‌بعدی Three.js، نورپردازی PBR و اسکرول دوربین
│       ├── calculator.js     # موتور محاسبات تبدیل اوزان، اجرت، سود و مالیات
│       ├── sound.js          # سنتز اصوات لوکس با Web Audio API
│       └── constants.js      # تعاریف اولیه دارایی‌ها و توابع کمکی تبدیل اعداد
│
├── data/                     # دایرکتوری داده‌های محلی (market.db و کش)
├── docs/                     # مستندات تکمیلی معماری
│   └── ARCHITECTURE.md
│
├── server.py                 # لانچر سریع سرور
├── run.sh                    # اسکریپت ران سریع در محیط یونیکس / لینوکس / مک
└── README.md
```

## 🚀 راهنمای نصب و اجرای سریع (Quickstart)

این پروژه با **کتابخانه استاندارد پایتون ۳** کار می‌کند و به نصب هیچ پکیج اضافی (مانند npm یا pip) نیاز ندارد:

### ۱. اجرای سرور
کافیست دستور زیر را در ترمینال اجرا کنید:

```bash
python3 server.py
# یا با استفاده از اسکریپت شل:
./run.sh
```

### ۲. مشاهده در مرورگر
آدرس زیر را در مرورگر خود باز کنید:
👉 **[http://localhost:8080/index.html](http://localhost:8080/index.html)**

## 📡 اندپوینت‌های REST API

* **دریافت تمام نرخ‌های روز و نمودارها:**
  `GET /api/rates`
* **دریافت تاریخچه نوسانات یک دارایی:**
  `GET /api/history?asset=gold18k&limit=50`
* **دستور همگام‌سازی فوری با TGJU:**
  `POST /api/sync`
